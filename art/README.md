# City Manager art

The cones: original artwork in Cities: Skylines II's flat two-tone style, made on 24 Nov 2026 (design "Skyline breaks
out"). Inspired by "it's all about the cones", with no text, names or logos.

| File | What it is |
|---|---|
| `CityManager-badge.svg` | The master art (1024 × 1024): the Paradox Mods thumbnail and the Discord server icon come from it |
| `../mod/src/CityManager/Properties/Thumbnail.png` | The Paradox Mods thumbnail, 1024 × 1024 (square, under 2 MB, as the game's upload panel asks) |
| `../mod/ui/images/CityManager-icon.svg`, `CityManager-icon-new.svg` | The button at the top left of the game, and the same with the orange "new update" dot |

Export the badge at another size with `rsvg-convert -w 512 -h 512 CityManager-badge.svg -o badge-512.png`.
